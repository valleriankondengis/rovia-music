# Hardware

The devices Rovia is developed and tested with.

- [Android device](ANDROID_DEVICE.md) — Xiaomi POCO F4, the test phone.
- [Cayin RU3](CAYIN_RU3.md) — the USB DAC.
- [Validated combination](VALIDATED_COMBINATION.md) — what the two run together.

A published DAC specification is not a statement of what Rovia supports
end to end; the validated combination records what the phone and the DAC
actually do with this app.
